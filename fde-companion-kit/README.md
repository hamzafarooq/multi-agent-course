# FDE Bootcamp: companion kit

Your workspace for the FDE Bootcamp companion. Open this folder in VS Code and Claude Code becomes your tutor: you ask in plain words, and it does the work and explains what it did. You won't need a terminal.

The videos, reading and step-by-step checklists are on the companion site: **https://fde-bootcamp-companion.vercel.app**. It follows the bootcamp's six modules. Before day one, do everything that's open (about two hours); new topics appear as the course goes on.

## What you need

- A **GitHub** account (free)
- A **Claude Pro or Max** plan
- **VS Code**, **Git**, and the **Claude Code** extension for VS Code

Topic 0.2 on the site walks you through each one.

## Get started

1. In VS Code, choose **File › Open Folder**, make an empty folder called `FDE Bootcamp` and open it.
2. Open the Claude panel and send: *Clone https://github.com/hamzafarooq/multi-agent-course into this folder, then tell me when it's done.* Claude asks before it runs Git: click **Allow**.
3. Choose **File › Open Folder** again and open `FDE Bootcamp › multi-agent-course › fde-companion-kit`.
4. Open the Claude panel and type `/companion`.

## What's in here

| | |
|---|---|
| `CLAUDE.md` | The tutor's instructions. Claude Code reads it at the start of every session. |
| `/companion` | Checks your setup and tells you what's next. |
| `/companion-explain <term>` | Explains any term from the companion, with the book section that covers it. |
| `glossary.md` | Every term in the companion so far. |
| `labs/` | The small files a few topics use: Parcelly's orders (1.1), your tip splitter (1.2, 1.3 and 2.1), and a client brief (5.1). |

Everything you make here stays on your laptop. In the bootcamp you'll work in your own repos.
