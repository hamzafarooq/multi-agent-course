# 1.1 · Watch the loop

`orders.json` holds four orders for **Parcelly**, a small delivery company. It's the same data as the loop you step through on the 1.1 page.

On the site you'll give Claude Code a customer's question about one of these orders. Claude Code is an agent: to answer, it has to read this file, decide what it needs, look it up and check the result. Then you'll ask it to walk you back through what it did as **Read → Plan → Act → Observe** (Book §3.2).
