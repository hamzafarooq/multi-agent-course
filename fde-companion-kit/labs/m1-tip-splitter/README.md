# 1.2 · Your first app: a tip splitter

A single web page: enter the bill, the tip percentage and the number of people, and it shows what each person pays.

The point isn't the app. It's practising how you direct Claude Code (Book §3.3–3.4):

1. **Plan first.** Switch the Claude panel to plan mode and ask for a plan, not code.
2. **Push back.** Change one thing in the plan before you approve it.
3. **Let it build**, then ask it to open the page in your browser.

In 1.3 you'll give this app its own `CLAUDE.md`, and in 2.1 you'll sketch what it would need to become a real AI product.
