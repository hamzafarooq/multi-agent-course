# FDE Bootcamp: pre-work starter kit

Your workspace for the FDE Bootcamp pre-work. Open this folder in VS Code and Claude Code becomes your tutor: you ask in plain words, and it does the work and explains what it did. You won't need a terminal.

The videos, reading and step-by-step checklist are on the pre-work site: **https://fde-starter.vercel.app**. The whole thing takes about two hours.

## What you need

- A **GitHub** account (free)
- A **Claude Pro or Max** plan
- **VS Code**, **Git**, and the **Claude Code** extension for VS Code

Module 1 on the site walks you through each one.

## Get started

1. In VS Code, choose **File › Open Folder**, make an empty folder called `FDE Bootcamp` and open it.
2. Open the Claude panel and send: *Clone https://github.com/hamzafarooq/multi-agent-course into this folder, then tell me when it's done.* Claude asks before it runs Git: click **Allow**.
3. Choose **File › Open Folder** again and open `FDE Bootcamp › multi-agent-course › fde-starter-kit`.
4. Open the Claude panel and type `/prework`.

## What's in here

| | |
|---|---|
| `CLAUDE.md` | The tutor's instructions. Claude Code reads it at the start of every session. |
| `/prework` | Checks your setup and tells you what's next. |
| `/prework-explain <term>` | Explains any pre-work term, with the book section that covers it. |
| `glossary.md` | Every term on the pre-work path. |
| `labs/` | The small files a few modules use: Parcelly's orders (M03), your tip splitter (M04–M06), and a client brief (M07). |

Everything you make here stays on your laptop. In the bootcamp you'll work in your own repos.
